## Running the pipeline

```bash
# Judge real transcripts (requires ANTHROPIC_API_KEY)
python3 sources/judge.py --input example_data/sweep_transcript_example.jsonl \
                          --output judged.jsonl

# Generate figures
python3 sources/roc_analysis.py \
  --sweep example_data/sweep_transcript_example.jsonl \
  --judged judged.jsonl \
  --output figures/
```
